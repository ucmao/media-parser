# 好看视频 (Haokan) 逆向解析指南

本篇详细记录百度旗下 **好看视频** 短视频的逆向提取方案。

---

## 1. 平台特征与支持能力

* **平台标识**：`好看视频`
* **支持媒体类型**：无水印高清视频 (MP4) / 视频封面 / 标题与作者
* **常见链接形态**：
  * 网页链接：`https://haokan.baidu.com/v?vid=17831460188721240800`
* **Cookie 依赖**：无需 Cookie。

---

## 2. 核心逆向流程

1. **提取 VID**：从 Query 中提取 `vid` 参数。
2. **提取 HTML 内嵌视频源**：
   * 请求好看视频播放落地页；
   * 正则匹配 `playurl` 或 HTML 内的 `<video>` 播放源链接。

---

## 3. 测试与验证

* **样本验证**：`python tests/manual_verify_parsers.py --platform 好看视频`
