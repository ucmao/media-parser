FREQUENTLY ASKED QUESTIONS

常见问题解答

解答你在对接与使用 Media Parser API 过程中的常见疑问。

解析出来的视频和图集是高清无水印的吗？

Media Parser 会尽量返回目标平台当前可获取的原始媒体地址，不主动对资源进行二次压缩。实际清晰度和水印情况取决于作品、平台接口、登录状态及平台后续调整，无法对所有链接作统一保证。

提取出的音视频/图片直链会过期或遭遇防盗链吗？

可能会。媒体地址通常由目标平台的 CDN 提供，可能包含时效签名、登录校验或防盗链策略，具体有效期由平台决定。对于拥有合法保存权且需要持久化的内容，请在解析后及时转存到自己的存储服务。

遇到目标平台改版导致解析失败怎么办？

请先更新到项目最新版本，并检查该平台是否需要 Cookie 等额外配置。如果问题仍然存在，可携带脱敏后的示例链接和错误日志提交 GitHub Issue。开源自部署实例不会自动热更新，升级前请先在自己的环境中验证。

如何获取和配置 API Key？

自部署后，首次访问 /auth/setup 创建管理员。用户登录控制台后可以创建和管理自己的 API Key；调用接口时推荐使用 Authorization: Bearer mp_xxx，也兼容 ?key=mp_xxx 查询参数。

QPS、有效期和解析积分如何配置？

这些限制均由自部署实例的管理员配置，并非固定商业套餐。默认新用户试用期为 7 天、初始积分为 100、账号限制为 2 QPS；管理员可在后台调整。触发 QPS 限制时返回 429，积分耗尽时返回 402，账号未开通或过期时返回 403。
