1. 接口鉴权机制

解析接口调用必须携带有效的 API Key 凭证。为了避免访问日志或浏览器记录泄露密钥，强烈推荐使用标准 HTTP Header 鉴权方式。

鉴权项 传递位置 语法示例 / 填写说明
Authorization HTTP Header 你的 API Key 凭证。Authorization: Bearer <API_KEY> 推荐
key URL Query URL 查询参数。?key=<API_KEY> 兼容模式

2. 请求参数规范

接口采用 HTTP GET 方法请求，参数如下：

参数名 位置 类型 是否必选 说明与填写规范
url Query String 必选 目标分享链接或包含分享文本的完整字符串（系统将自动提取文案中的 http/https 链接，长度限 2000 字符内）。
Authorization Header String 推荐 标准 Bearer 授权凭据。格式：Bearer mp_xxxxxxxxxxxx
key Query String 可选 未携带 Authorization Header 时的兼容授权参数。

3. 返回 JSON 数据字典

所有接口返回标准的 JSON 结构，包含全局状态标识与媒体详情数据：

3.1 基础返回格式

字段名 类型 业务含义与说明
succ Boolean 请求是否成功：true 成功；false 失败。
retcode Integer 业务响应状态码。成功时为 200，失败时为对应 HTTP 状态（如 400, 401, 402, 429, 503 等）。
retdesc String 提示信息或官方/系统异常原因说明。
error_code String 失败时返回的机器可读标准错误标识（如 MEDIA_DELETED_OR_PRIVATE、NO_MEDIA_IN_CONTENT、RATE_LIMITED 等，详见第 5 节）。
data Object / null 解析成功返回的媒体实体数据对象，失败时为 null。

3.2 媒体数据主体 (data 字段)

字段名 类型 说明与数据含义
platform String 自动识别出的平台名称（如：抖音、哔哩哔哩、快手、小红书 等）。
video_id String 源平台作品的全局唯一 ID。
title String 作品标题或文案摘要。
desc String 作品完整文本描述。
cover_url String 作品高清主封面图 HTTPS 直链。
video_url String 无水印视频 MP4 直链（纯图集作品时为空字符串）。
video_list Array 可选。包含多清晰度（1080P/720P）或备用播放源直链数组。
image_list Array 高清图集直链数组（支持 LivePhoto 动态图片）。
audio_url String 提取出的背景音乐或纯音频直链（MP3 / M4A）。
author Object 创作者信息对象：{ "name": "作者名", "avatar": "头像URL", "uid": "ID" }

5. 标准错误码与排错指南

                    
当请求处理发生异常时，接口返回 {"succ": false, "code": "...", "message": "..."}：

                    

                        

                            
                                

                                    HTTP 状态
                                    错误标识 (Code)
                                    原因分析与排查指引
                                

                            
                            
                                

                                    400
                                    INVALID_TEXT
                                    请求 URL 参数为空，或文案长度超过了 2000 个字符限制。
                                

                                

                                    400
                                    URL_NOT_FOUND
                                    文本中未提取到合法的 http/https 链接，请检查分享文本是否完整。
                                

                                

                                    400
                                    PLATFORM_NOT_SUPPORTED
                                    目标平台域名不在支持列表中。
                                

                                

                                    400
                                    MEDIA_DELETED_OR_PRIVATE
                                    目标内容为私密作品、仅好友可见的日常/动态，或已被作者删除下架。
                                

                                

                                    400
                                    NO_MEDIA_IN_CONTENT
                                    目标分享内容（如 AI 问答对话）仅包含文本，未包含图片或视频多媒体资源。
                                

                                

                                    400
                                    MEDIA_NOT_FOUND
                                    未能从该链接提取到媒体内容，请检查链接有效性或稍后重试。
                                

                                

                                    400
                                    COOKIE_REQUIRED
                                    目标平台需要服务端 Cookie 凭据校验（如小红书 XIAOHONGSHU_COOKIE_REQUIRED、拼多多 PINDUODUO_COOKIE_REQUIRED、微信视频号 WECHAT_CHANNELS_COOKIE_REQUIRED 等）。请在管理后台「系统设置 - Cookie管理」中配置有效凭据。
                                

                                

                                    401
                                    API_KEY_REQUIRED
                                    请求头或查询参数中未提供 API Key 凭证。
                                

                                

                                    401
                                    INVALID_API_KEY
                                    提供的 API Key 不存在或已被删除。
                                

                                

                                    403
                                    API_KEY_DISABLED
                                    该 API Key 或关联的客户账号已被管理员停用。
                                

                                

                                    403
                                    ACCOUNT_EXPIRED
                                    账号使用期限已到期，请联系管理员续期。
                                

                                

                                    402
                                    INSUFFICIENT_CREDITS
                                    账号可用解析积分已耗尽（剩余 0 点），请充值或调整额度。
                                

                                

                                    429
                                    RATE_LIMITED
                                    超出当前账号、API Key 或平台的并发 QPS 阈值，请在客户端增加重试与指数退避。
                                

                                

                                    503
                                    API_DISABLED
                                    系统全局 API 服务或特定平台被管理员临时维护关闭。
